## 2. P0-1：数据清洗规则会误杀 100% 合法 run（已修正）

**声明（原文）**："`records == 99`（30 s / 250 ms）"；"`elapsed_ms` 间隔 250±30 ms"。

**代码事实**：

- 采样门限 `CAPTURE_SAMPLE_PERIOD_MS = 250`（`radar_capture.c:26`），但 tick 由 LVGL poll 驱动，**poll 周期 100 ms**（`main.c:1049`）；
- 门限被 poll 栅格量化：实际采样间隔 = 300 ms；30 s 采集窗（`CAPTURE_RUNNING_MS = 30000`）→ **期望 100 条**（99~100 取决于相位），上限 `RADAR_CAPTURE_MAX_RECORDS = 128`；
- 30 s ÷ 250 ms = 120 ≠ 99，原括号里的算式自身就不成立。

**后果**：按原文规则，每一条正常 run 都会因"记录数不等于 99"与"间隔不是 250±30"被判 `SUSPECT`——拟合前的清洗把全部数据杀光，后面的统计结论全部无从谈起。

**修正**（更新程序 §4/§4.1，中英同步）：期望 `records = 100`，`95~102` 视为完整；间隔 ≈300 ms（合法 250~450 ms，>500 ms 记一次丢拍）。

## 3. P0-2：`target_m` 当真值与补救设计冲突（已修正）

**声明（原文）**：§2.1 "采集时用户输入的是 `target_m`（卷尺/激光测距真值）"；§4.1.4 `b0_run = ftm_raw_median_m − target_m`；§6.3 YAML `tape_distance_m`。

**冲突事实**：补救设计 R-03 与 80% 评审 P0-DATA-3 已钉死——`target_m` 是预设**标签**（LABEL ONLY），权威真值是 sidecar 提交的 `measured_distance_m`。按原文，P1 偏移拟合 `b0 = median − target` 在标签误差下直接算错，正是评审警告过的"校正模型被喂错数据"。

**修正**（中英同步）：§2.1 / §4.1.4 / §6.3 / §8 一致性表全部改用 `measured_distance_m`；无实测真值的 run 不进正式拟合；YAML sidecar 与 `DISTANCE_SIDECAR_*` 对齐校验挂钩补救设计 §4.1。

## 4. P0-3：Wilson 表 90% 行数学错误，D6 样本量不足（已修正）

**独立复算**（Wilson 95% 下界 ≥0.8 所需最小 n，z=1.96）：

| 观测命中率 | 原文档 | 复算 | 点值验证 | 判定 |
| --- | --- | --- | --- | --- |
| 100% | ≥16 | ≥16 | n=15 → 0.796；n=16 → 0.806 | ✓ |
| 95% | ≥30 | ≥30 | n=30 → 0.810 | ✓ |
| 90% | ≥40 | **≥65** | n=40 → **0.769**；n=60 → 0.799；n=65 → 0.803 | ✗ 已修正 |
| 85% | ≈250 | ≈250 | n=250 → 0.800 | ✓ |
| 80% | 不可能 | 不可能 | 点估计=阈值时下界必低于阈值 | ✓ |

**后果**：按原 D6（每场景 40~60 run）采回的数据，即使真实命中率 90%，也只能证明到 77%——验收时"证明不了 80%"会被误读为能力不足，或反过来迫使放宽判据。

**修正**（80% 评审 §6.2/§8.1 + slot2 §3.2，中英同步）：D6 改为按预期命中率分层——≈90% 场景 ≥65 个独立 run、≥95% 场景 ≥30 个；slot2 计划补「拟合集与验证集分离」专段。

## 5. P1-1：n̂ 置信宽度门限 ≤0.4 在现实散布下不可达（已修正为三级门限）

**复算**：n̂ 的 95% 区间宽度 ≈ `2·t·σ̂/(10·√Sxx)`：

| 距离点布局 | Sxx | 宽度系数 | σ̂=1.5 dB | σ̂=3 dB |
| --- | --- | --- | --- | --- |
| 8 点 1/3/5/8/10/15/20/30 m（跨度 1.48） | 1.61 | 0.39·σ̂ | 0.58 | 1.16 |
| 5 点 1/2/3/5/8 m（跨度 0.90） | 0.49 | 0.91·σ̂ | 1.37 | 2.73 |

run 级 RSSI 残差 σ̂ 的现实量级是 1.5~3 dB，即原门限（≤0.4）连最优布局都过不了 → P3/P4 永远回退编译期值，中远距 T3 区间失去拟合支撑。

**修正**（更新程序 §4.2.1 注 + §4.6，中英同步）：三级门限——≤0.4 直接采用（`n_ci_tight`）；(0.4, 0.8] 采用但标 `n_ci_wide` 并注明外推风险；>0.8 拒绝、回退编译期值。宽度算例写入文档，作为 D7 距离点要求的推导依据。

## 6. P1-2：D7 跨度表述歧义（已修正）

**原文**："每条件 ≥5 距离点（含 ≥2 个十倍距跨度）"。字面 = 跨度 100×（1 m→100 m），室内物理不可能，落地时必然各执一词。

**修正**（中英同步）：精确化为"**每条件 ≥5 个距离点且 log10 跨度 ≥1.4**（约 1–30 m，如 1/3/5/10/20/30 m）"——由 §5 的宽度算式反解得出；室内 1~8 m 跨度不足属预期（室内 P3 回退编译期 n），不再有歧义。
